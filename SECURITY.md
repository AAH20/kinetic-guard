# Security & Kinetic Safety Policy

## Safety-Critical Systems Warning
`kinetic-guard` is designed for physical robotics, autonomous actuators, and cyborg cybernetics where software failures can produce kinetic destruction or human harm.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability or Invariant Bypass
If you discover a mathematical vulnerability, constraint bypass, watchdog deadlock, or timing jitter flaw in `kinetic-guard`:
1. **Do not** open a public issue.
2. Email the maintainers directly at **security@a2zsoc.com** with the subject line `[CRITICAL-SAFETY] kinetic-guard invariant vulnerability`.
3. Provide robot dynamics model, joint trajectory, mathematical proof, and reproduction script.
4. Security and safety disclosures will be acknowledged within 12 hours.
